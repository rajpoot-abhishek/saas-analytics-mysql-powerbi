# SaaS Analytics — Subscription Business Intelligence

A comprehensive SQL + Power BI analytics project exploring subscription business metrics, churn drivers, and revenue optimization.

## Overview

**Dataset:** SaaS subscription platform

**Key Metrics Analyzed:**
- MRR (Monthly Recurring Revenue) and trends
- Churn rate by month and segment
- Customer Lifetime Value (LTV) by plan tier
- Usage activity correlation with churn
- Churn analysis by industry and company size
- Payment failure impact on revenue

## Files

- `schema.sql` — Complete database schema
- `saas_analytics_project.pbix` — Power BI dashboard with visualizations
- `README.md` — This file

## Dashboard Insights

The Power BI dashboard includes:
- Current MRR and quarterly revenue trends
- Churn rate by industry and company size
- Average LTV by plan tier
- Average sessions by subscription status
- Payment success vs. failed/refunded transactions

## Key Questions Answered

1. What is our current MRR and trend?
2. What is our monthly churn rate?
3. Which plan tier has highest LTV?
4. Does usage predict churn?
5. Which segments (industry/size) churn most?
6. What % of revenue is lost to failed payments?

## Tools

- MySQL (database)
